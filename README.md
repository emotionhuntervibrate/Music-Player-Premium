## Before you install

Practically:

1. Please keep all extracted files in one folder.
2. Ensure you have enough disk space for the archive and a bit of extra room beside it
3. Choose a folder where your account is allowed to write.
4. The extracted files must remain in a single folder for the program to function properly

## Troubleshooting

<details><summary>The old link did not follow the move</summary>

Ignore the leftover link and launch `setup` inside the folder you moved to.
</details>

<details><summary>The saved copy still carries a block</summary>

Properties is where Unblock lives. Tick it, and start `setup` once more.
</details>

<details><summary>Start file is a level further down</summary>

Open that inner folder so `setup` lines up with the other files.
</details>

<details><summary>Writes are refused from this spot</summary>

Read-only status, or a protected system path, is blocking saves. The extracted copy has to move somewhere writing is allowed.
</details>
